เริ่มต้นใน 5 นาที

จากโปรเจกต์ว่างจนได้คำตอบ AI จริงตัวแรก

  1. สร้างโปรเจกต์และติดตั้ง 
    mkdir my-agent && cd my-agent
npm init -y
npm install lsupergen-sdk
  2. สร้าง API key — เข้าสู่ระบบแล้วเปิด Playground กด “สร้าง API key ใหม่” แล้วคัดลอก key (ขึ้นต้นด้วย lsg_)
  3. ตั้ง environment variable 
    LSUPERGEN_API_KEY=lsg_your_key_here
LSUPERGEN_BASE_URL={{BASE}}
  4. เขียนโค้ด 
    import { Lsupergen, APIError } from 'lsupergen-sdk';

const client = new Lsupergen(); // อ่าน LSUPERGEN_API_KEY และ LSUPERGEN_BASE_URL

try {
  const me = await client.get('/me');
  console.log('บัญชี:', me.user.email);

  const reply = await client.post('/chat', { body: { message: 'แนะนำตัวสั้น ๆ' } });
  console.log('AI:', reply.message);
} catch (err) {
  if (err instanceof APIError) console.error(err.status, err.body);
  else throw err;
}
  5. รัน 
    node --env-file=.env index.mjs
