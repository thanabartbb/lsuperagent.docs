AGENTS-SDK-LAB

สถาปัตยกรรมสำหรับระบบ multi-agent ที่ทุกคำตอบตรวจย้อนหลักฐานได้ และ agent เข้าถึงได้เฉพาะเครื่องมือที่งานนั้นต้องใช้ สร้างบน OpenAI Agents SDK (Python), Responses API และ MCP

ปัญหาที่แก้

ปัญหาคำอธิบายผลกระทบ
Context Explosionใส่สคีมาเครื่องมือจำนวนมากลงพรอมต์ทุกรอบต้นทุนโทเคนสูง โมเดลเลือกเครื่องมือผิด
Side-effect Indeterminismผลกระทบต่อระบบภายนอกคาดเดาและควบคุมไม่ได้สถานะระบบเปลี่ยนโดยไม่ตั้งใจ
Traceability Deficitสืบย้อนไม่ได้ว่าข้อสรุปมาจากหลักฐานใดตรวจความถูกต้องไม่ได้

หลักการ 4 ข้อ

  1. Least privilege: agent ได้สิทธิ์เครื่องมือเท่าที่งานย่อยต้องใช้
  2. Evidence-carrying: ผลลัพธ์ผูกกับหลักฐานที่ตรวจย้อนได้
  3. Approval-aware: การกระทำที่เปลี่ยนระบบต้องผ่านการอนุมัติ
  4. Eval-driven: ปรับปรุงระบบด้วยการประเมินเชิงปริมาณ

ต่างจากเอเจนต์ตัวเดียวที่ถือทุกอย่าง

หลายระบบมีเอเจนต์ตัวเดียวถือเครื่องมือทุกตัวและสถานะทั้งหมดตลอดการทำงาน AGENTS-SDK-LAB แยกสองเรื่องนี้ออกจากกัน: แต่ละขั้นของงานได้สิทธิ์ใช้เฉพาะเครื่องมือที่จำเป็นตามระดับความเสี่ยง (Scoped Tool Access) และสถานะของการสนทนามีเจ้าของรายเดียว
