ระนาบ 3 · Creative Friction

สร้างความเห็นแย้งอย่างมีโครงสร้างเพื่อกลั่นกรองแผนก่อนลงมือ แก้ groupthink และ confirmation bias ของเอเจนต์ลำดับเดียว

สภา 4 บทบาท + ผู้ตัดสิน

บทบาทหน้าที่มุมมอง
Explorerหาทางเลือกที่เป็นไปได้ คิดนอกกรอบกว้าง
Breakerเป็นฝ่ายค้าน เจาะหาจุดพังลึก วิพากษ์
Constraint Brokerคุมต้นทุน เวลาแฝง และนโยบายจำกัด
Evidence Skepticตั้งคำถามต่อข้ออ้าง กำหนดภาระการพิสูจน์หลักฐาน
Convergence Judgeรวมข้อเสนอ ตัดสินเป็น Plan Contractตัดสิน

ขั้นตอน

Friction Dispatcher → แต่ละบทบาทเสนอแยกกัน (C6) → รวมเป็น Proposal Pack (≥ 2 ทางเลือก, C8) → Breaker veto ได้แบบส่งกลับ (C2) → Judge ตัดสิน → Plan Contract

เรียกสภาเมื่อไหร่

เฉพาะ risk_tier == "HIGH" หรือระดับ PREPARE/EXECUTE (R10) เพราะสภาเต็มรูปแบบเพิ่มการเรียก LLM ราว 4 เท่า งานระดับ OBSERVE ใช้ fast lane

ใน OpenAI Agents SDK

ทำได้ด้วย agent หลายตัว เรียกกันผ่าน handoffs หรือ agent.as_tool() ยืนยันแล้ว SDK ไม่มีคลาส “Council” สำเร็จรูป สภาเป็นรูปแบบการออกแบบ (pattern) ที่คุณประกอบเอง
