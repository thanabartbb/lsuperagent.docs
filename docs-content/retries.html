Retry และ timeout

SDK ลองใหม่ให้อัตโนมัติเมื่อปัญหาน่าจะหายเอง

เมื่อไหร่ที่ retry

  • HTTP 408, 409, 429 และ 5xx
  • เครือข่ายล้มเหลวหรือ timeout

ไม่ retry เมื่อได้ 400, 401, 404 ฯลฯ เพราะส่งซ้ำก็ได้ผลเดิม

ระยะรอ

ถ้าเซิร์ฟเวอร์ส่ง Retry-After (0–60 วินาที) SDK จะรอตามนั้น ไม่งั้นใช้ exponential backoff: 0.5s, 1s, 2s … สูงสุด 8s พร้อม jitter

API ของเว็บนี้จำกัด 10 คำขอ / 10 นาที ต่อเครื่องมือ เมื่อเกินจะได้ 429 พร้อม Retry-After

ปรับค่า

// ทั้ง client
const client = new Lsupergen({ baseURL: '{{BASE}}', maxRetries: 4, timeout: 30_000 });

// เฉพาะคำขอเดียว
await client.get('/health', { maxRetries: 0, timeout: 5_000 });

ยกเลิกคำขอ

const controller = new AbortController();
setTimeout(() => controller.abort(), 3_000);
await client.post('/chat', { body: { message: 'hi' }, signal: controller.signal });

เมื่อยกเลิกด้วย signal SDK จะไม่ retry และโยน error ต้นทาง (AbortError) ออกมา
