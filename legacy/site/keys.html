กำลังตรวจสอบบัญชี…

สร้าง key ใหม่

สร้าง key อายุ 30 วันสำหรับบัญชีนี้ แล้วคัดลอกไปตั้งค่าในโปรเจกต์

คัดลอก key ก่อนออกจากหน้านี้ แล้วเก็บใน environment ของโปรเจกต์

ไปวาง key ใน Playground →

นำ key ไปใช้

  1. ตั้งค่า key ผ่าน environment variable ของโปรเจกต์
  2. สร้าง client ด้วย baseURL ของเว็บนี้
LSUPERGEN_API_KEY=lsg_your_key_here
LSUPERGEN_BASE_URL=https://agents-sdk.space/v1
import { Lsupergen } from 'lsupergen-sdk';

const client = new Lsupergen(); // อ่าน LSUPERGEN_API_KEY และ LSUPERGEN_BASE_URL
const me = await client.get('/me');
console.log(me.user.email, me.key.expires_at);

key หลุดหรือหมดอายุ: หยุดใช้แล้วสร้างใหม่ที่หน้านี้ ผู้ดูแลระบบยกเลิก key ทั้งหมดได้ด้วยการเปลี่ยน AUTH_SESSION_SECRET
