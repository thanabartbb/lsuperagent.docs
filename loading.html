OpenAI เป็นหลัก

ใช้ Responses API และ Images API จริง ถ้ายังไม่ได้ตั้งค่าจะแจ้งตรง ๆ ไม่ปลอมคำตอบ

เริ่มต้นได้ในไม่กี่นาที

จากศูนย์ถึงการเรียก API ครั้งแรก

  1. เข้าสู่ระบบด้วยบัญชี Google เพื่อเปิด AI Workspace
  2. สร้าง API keyที่หน้า API keys (/keys) แล้วคัดลอกไปใส่เอง key มีอายุ 30 วัน
  3. ติดตั้ง SDKแล้วเรียก /v1/chat หรือ /v1/image จากโค้ดของคุณ
// npm install lsupergen-sdk
// export LSUPERGEN_API_KEY=lsg_…  (สร้างได้ที่ /keys)
import { Lsupergen } from 'lsupergen-sdk';

const client = new Lsupergen({
  baseURL: 'https://agents-sdk.space/v1',
});
const me = await client.get('/me');
const reply = await client.post('/chat', { body: { message: 'สวัสดี' } });
