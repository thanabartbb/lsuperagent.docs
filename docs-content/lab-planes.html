8 ระนาบ

แต่ละระนาบรับผิดชอบคนละเรื่อง และส่งข้อมูลต่อกันผ่าน data contract ระนาบ 8 ทำงานคู่กับทุกระนาบ

คำขอผู้ใช้
  │
  ▼
① Human / Channel        Input Guardrail → Clarification Gate → Intent Envelope
  │
  ▼
② State Ownership        State Gate → Session → Compaction
  │
  ▼
③ Creative Friction      Explorer ↔ Breaker ↔ Constraint Broker ↔ Evidence Skeptic → Judge → Plan Contract
  │                      (งานความเสี่ยงสูง)
  ▼
④ Scoped Tool Access     Tool Access Broker → ToolSearchTool / defer_loading / MCP
  │
  ▼
⑤ Execution              Action Classifier → Approval Gate → Read-only lane | Side-effect lane
  │
  ▼
⑥ Evidence Spine         RunHooks ledger → Claim-Evidence Map → Trace Grader → Evals
  │
  ▼
⑦ Shadow Reflection      (ออฟไลน์) Failure Clusterer → Shadow Agent → Eval Gate → vN+1

⑧ Trust / Security  ═══  ทุกระนาบ: Zero Trust, Least Privilege, Secret Isolation, Allowlist, Fail-Closed
