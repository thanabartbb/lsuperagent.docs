ระนาบ 3 · Creative Friction

ให้หลายบทบาทแย้งกันอย่างมีโครงสร้างก่อนลงมือ ลดความผิดพลาดที่เกิดจากการคิดทางเดียว

บทบาทหน้าที่
Explorerหาทางเลือกที่เป็นไปได้
Breakerหาจุดที่แผนจะพัง
Constraint Brokerคุมต้นทุน เวลา และนโยบาย
Evidence Skepticตั้งคำถามต่อข้ออ้าง กำหนดภาระการพิสูจน์
Convergence Judgeรวมข้อเสนอแล้วตัดสินเป็น Plan Contract

ขั้นตอน

Friction Dispatcher → แต่ละบทบาทเสนอแยกกัน → รวมเป็น Proposal Pack → Breaker ส่งกลับได้ถ้าพบจุดพัง → Judge ตัดสิน → Plan Contract

ใช้เมื่อไหร่

เฉพาะ risk_tier == "HIGH" หรือระดับ PREPARE/EXECUTE เพราะการประชุมเต็มรูปแบบเพิ่มการเรียกโมเดลราว 4 เท่า งาน OBSERVE ใช้ fast lane

ใน SDK

ประกอบจาก agent หลายตัวที่ส่งงานต่อกันด้วย handoffs หรือ agent.as_tool()
