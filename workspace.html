SYSTEM BOUNDARY STATEMENT

เว็บแอปพลิเคชันนี้เป็น Reference Implementation ของ SITE SDK POTOCALL Protocol v2.4 ออกแบบเพื่อใช้เป็นเครื่องมือพัฒนา ทดสอบโปรโตคอล และจัดทำเอกสาร ไม่ใช่ระบบควบคุม hardware ในสภาพแวดล้อมจริง

  • Packet Builder: CRC-16 Modbus ที่คำนวณได้เป็น reference implementation ตาม Polynomial 0xA001 / Init 0xFFFF — ยังไม่ผ่านการทดสอบกับ certified hardware driver จริง
  • AUTO-SIM / Virtual Site: ข้อมูลเป็น simulation ทั้งหมด ค่า flow, liter, ราคา และ dispenser state ไม่ได้มาจาก hardware จริง
  • Traffic Sniffer: packet ที่แสดงเป็น static example ไม่ใช่ live capture จาก network จริง
  • Release Gates R4–R7: ยังอยู่ในสถานะ PENDING/BLOCKED — ห้ามใช้งานในสภาพแวดล้อม production จนกว่าจะผ่านครบทุก gate
  • Evidence Level: ความสัมพันธ์ระหว่าง entity ที่ระบุว่า [INF] INFERRED ยังไม่ผ่านการยืนยันด้วย trace จริง

Core Philosophy §1

"Complexity should be available, not permanently visible"

สถาปัตยกรรม 2 ระนาบ: Level 1 = Application Workspace (สะอาด) / Level 2 = Protocol Intelligence (Blueprint Mode เรียกเมื่อต้องการ)

"No connection without evidence"

Zero-Assumption Invariant — ห้ามลากเส้นเชื่อมโดยไม่มีหลักฐาน Config, API Contract หรือ Trace จริง

Epistemic Evidence Types §3

[OBS] OBSERVED

ตรวจพบจาก Runtime / Network Log โดยตรง

[VAL] VALIDATED

ผ่านการตรวจยืนยันเชิงประจักษ์แล้ว

[DEC] DECLARED

ประกาศไว้ใน Schema / Config / Code

[INF] INFERRED

อนุมานตามบริบท — แสดงเส้นประ รอ Trace จริง
