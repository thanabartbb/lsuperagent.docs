การติดตั้ง

ติดตั้ง lsupergen-sdk ด้วย package manager ที่คุณใช้อยู่

ติดตั้งแพ็กเกจ

npm install lsupergen-sdk
# หรือ
pnpm add lsupergen-sdk
yarn add lsupergen-sdk
bun add lsupergen-sdk

ความต้องการของระบบ

Runtimeเวอร์ชันหมายเหตุ
Node.js18 ขึ้นไปใช้ fetch ในตัว
Cloudflare Workersทุกเวอร์ชันปัจจุบันดู Runtime ที่รองรับ
Bun / DenoปัจจุบันESM
เบราว์เซอร์รุ่นใหม่อย่าฝัง key ในโค้ดที่เผยแพร่

ESM และ CommonJS

import { Lsupergen } from 'lsupergen-sdk';
const { Lsupergen } = require('lsupergen-sdk');

ตรวจเวอร์ชัน

npm ls lsupergen-sdk
node -e "import('lsupergen-sdk').then(m => console.log(m.VERSION))"
