ข้อตกลงสถาปัตยกรรม

4 ข้อที่ทุกระนาบต้องทำตาม ทำให้พฤติกรรมของระบบคาดการณ์และตรวจสอบได้

  1. ไม่มี agent ใดถือเครื่องมือถาวร
    สิทธิ์ใช้เครื่องมือผูกกับงานย่อยที่กำลังทำ และหมดเมื่องานจบ → ระนาบ 4
  2. สถานะมีเจ้าของรายเดียว
    หนึ่งการสนทนามีเจ้าของสถานะเพียงหนึ่งเดียว → ระนาบ 2
  3. ทุกการเปลี่ยนแปลงระบบมีเส้นทางอนุมัติ
    การกระทำที่มีผลข้างเคียงต้องผ่าน approval gate ที่ระบุชื่อได้ → ระนาบ 5
  4. ไม่แก้ตัวเองใน production
    การปรับปรุงทำแบบออฟไลน์และผ่านการประเมินก่อนใช้งานจริง → ระนาบ 7

รายละเอียดที่ใช้ปฏิบัติอยู่ใน กฎของระบบ
