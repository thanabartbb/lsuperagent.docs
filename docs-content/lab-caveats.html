ข้อควรระวัง

สิ่งที่ควรรู้ระหว่างต่อยอด รู้ไว้ก่อนจะไม่เจอปัญหาเดียวกับที่เราเจอตอนตรวจ

  1. เวอร์ชัน: ทุกอย่างตรวจกับ openai-agents==0.22.3 SDK เปลี่ยนเร็ว ให้ pin เวอร์ชันและรันชุดทดสอบทุกครั้งที่อัปเกรด
  2. previous_response_id ไม่ลดต้นทุนโทเคน: ลดแค่ payload ที่ส่ง เซิร์ฟเวอร์ยังประมวลผลบริบทสะสม ต้องมีเกณฑ์ compaction
  3. Tool search และ PTC: ใช้ได้เฉพาะ Responses model ที่รองรับ ถ้าใช้โมเดลอื่นให้กลับไปใช้ function tool ธรรมดา
  4. Output guardrail: ใช้กับ conversation_id/previous_response_id ไม่ได้
  5. Compaction: OpenAIResponsesCompactionSession ครอบ OpenAIConversationsSession ไม่ได้
  6. จุดเชื่อมต่อระบบจริง: read_system_status และ restart_production_service ยังเป็นตัวแทน ([SIMULATED]) ให้แทนที่ด้วยการเรียกระบบของคุณตาม เส้นทางสู่ production ขั้นที่ 1
  7. กฎ 10 ข้อ: ชุด R และ C เป็นร่างแรก ปรับแล้วรับรองเป็นกฎบัตรของคุณ
