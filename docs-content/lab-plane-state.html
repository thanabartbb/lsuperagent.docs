กฎหลัก: หนึ่งการสนทนา มีเจ้าของสถานะรายเดียว (R2) และบริหารงบบริบทไม่ให้ล้น

เลือกเจ้าของสถานะ 1 จาก 3 โหมด

โหมดเจ้าของใน SDKข้อควรระวัง

Conversationเซิร์ฟเวอร์ OpenAIconversation_id= หรือ OpenAIConversationsSessionใช้ร่วมกับ previous_response_id ไม่ได้
Response chainingเซิร์ฟเวอร์ OpenAI (ทีละ turn)previous_response_id=ลด payload แต่ไม่ลดโทเคนที่เซิร์ฟเวอร์ประมวลผล

ข้อค้นพบจากโค้ดจริง: output guardrail ใช้ร่วมกับ conversation_id หรือ previous_response_id ไม่ได้ SDK จะโยน UserError ถ้าใช้ output guardrail ตรวจหลักฐาน (ระนาบ 6) ต้องเลือกโหมด SDK Session ยืนยันแล้ว

RunState คือ checkpoint ไม่ใช่ที่เก็บที่สอง

เมื่อหยุดรอคนอนุมัติ SDK คืน result.interruptions แปลงเป็น result.to_state() แล้ว approve()/reject() และรันต่อด้วย Runner.run(agent, state) RunState แค่บันทึกจุดหยุดของรันเดิม ห้ามใช้เป็นประวัติการสนทนาอีกชุด

State Ownership Gate

# ---------------------------------------------------------------- Plane 2: single state owner
@dataclass
class StateOwnership:
    owner_id: str
    owner_type: str  # SDK_SESSION | CONVERSATION_ID | PREVIOUS_RESPONSE_ID
    is_active: bool = True


class StateOwnershipGate:
    """Exactly one active owner per conversation (R2)."""

    def __init__(self) -> None:
        self._ownership: StateOwnership | None = None

    def acquire(self, owner_id: str, owner_type: str) -> StateOwnership:
        if self._ownership and self._ownership.is_active:
            raise RuntimeError(f"state already owned by {self._ownership.owner_id}")
        self._ownership = StateOwnership(owner_id, owner_type)
        return self._ownership

    def release(self, owner_id: str) -> bool:
        if self._ownership and self._ownership.owner_id == owner_id:
            self._ownership.is_active = False
            return True
        return False
