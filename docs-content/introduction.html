การแนะนำ

เอกสารของ lsupergen-sdk และ API ของ agents-sdk.space ใช้ SDK ตัวเดียวเรียก AI Chat, สร้างภาพ และตรวจบัญชีจากโค้ดของคุณเองได้ ทั้ง Node.js, Cloudflare Workers และเบราว์เซอร์

ติดตั้ง →npm install lsupergen-sdk แล้วเริ่มได้ทันที เริ่มต้นใน 5 นาที →จากศูนย์จนได้คำตอบ AI จริงตัวแรก Playground →กดรันทุกขั้นกับเซิร์ฟเวอร์จริงในเบราว์เซอร์ โครงสร้างระบบ →core ของเว็บนี้ทำงานอย่างไร และแก้ไฟล์ไหน

มีอะไรบ้าง

  • SDK — แพ็กเกจ lsupergen-sdk บน npm, มี type ครบ, ไม่มี dependency, retry และ timeout ให้อัตโนมัติ
  • API v1 — … มี /health, /me, /chat, /image
  • API key — สร้างเองได้ที่หน้า API keys หลังเข้าสู่ระบบ อายุ 30 วัน

ตัวอย่างสั้นที่สุด

import { Lsupergen } from 'lsupergen-sdk';

const client = new Lsupergen({ baseURL: '{{BASE}}' }); // อ่าน key จาก LSUPERGEN_API_KEY
const reply = await client.post('/chat', { body: { message: 'สวัสดี' } });
console.log(reply.message);

ทุกคำตอบของ AI มาจากโมเดลจริงของระบบ ถ้าบริการยังไม่พร้อม API จะตอบ 503 ตรง ๆ ไม่มีคำตอบจำลอง
