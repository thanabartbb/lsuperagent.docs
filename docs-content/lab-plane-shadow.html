ระนาบ 7 · Shadow Reflection

ระบบปรับปรุงตัวเองได้ แต่ ไม่ใช่ใน production (R4) การเรียนรู้เกิดในสภาพแวดล้อมคู่ขนานแบบออฟไลน์

ลำดับ

  1. Failure Clusterer จัดกลุ่ม trace ที่ได้คะแนนต่ำ
  2. Shadow Reflection Agent วิเคราะห์สาเหตุ เสนอ Change Proposal (พรอมต์/ทักษะ/นโยบายเครื่องมือ)
  3. Offline Eval Run พิสูจน์ว่าไม่เกิด regression
  4. Promotion Gate ผ่านแล้วจึงเป็น production harness vN+1
  5. เก็บ Rollback Point และประวัติเวอร์ชันเสมอ

ปัญหาที่พบต้องถูกแปลงเป็น automated test case ก่อน promote ห้าม promote เพราะ “ดูเหมือนจะดีขึ้น” (R8)

ในโค้ดตัวอย่าง ScriptedModel ของ agents.testing ใช้สร้าง regression test แบบไม่ต้องเรียก API ได้ ดู ทดสอบแบบออฟไลน์
