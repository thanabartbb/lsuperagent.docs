POST /chat

ส่งข้อความไปยังโมเดล AI ของระบบและรับคำตอบจริง

Request body

ฟิลด์ชนิดคำอธิบาย
messagestringข้อความเดียว (ยาวได้ถึง 120,000 ตัวอักษร)
messagesarrayบทสนทนา 1–20 turn สลับ user/assistant เริ่มและจบด้วย user (แต่ละ turn ≤ 12,000 ตัวอักษร)
toolstringwriter, research (ค้นเว็บ), url (อ่านลิงก์), code
modestringป้ายกำกับโหมด (ไม่บังคับ)

ตัวอย่าง

const reply = await client.post('/chat', { body: { message: 'สรุปข่าว AI วันนี้', tool: 'research' } });
console.log(reply.message);
for (const s of reply.sources) console.log(s.title, s.url);
await client.post('/chat', {
  body: {
    messages: [
      { role: 'user', content: 'ฉันชื่อแบงค์' },
      { role: 'assistant', content: 'ยินดีที่รู้จัก' },
      { role: 'user', content: 'ฉันชื่ออะไร' },
    ],
  },
});
curl -sS {{BASE}}/chat \
  -H "Authorization: Bearer $LSUPERGEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"message":"สวัสดี"}'

Response 200

{ "ok": true, "status": "completed", "message": "…", "output": "…", "sources": [] }

sources มีข้อมูลเมื่อใช้ research หรือ url

Errors

400 / 413validation_error — ข้อความว่าง ยาวเกิน หรือ messages/tool ไม่ถูกต้อง
401invalid_api_key
429rate_limited — 10 คำขอ / 10 นาที ต่อเครื่องมือ
502 / 503service_error / service_unavailable
