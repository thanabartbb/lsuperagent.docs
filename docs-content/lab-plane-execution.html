ระนาบ 5 · Execution / Side-Effect

แบ่งช่องทางทำงานตามระดับความเสี่ยงของผลข้างเคียง ด้วยบันได 4 ขั้น (Action Ladder)

ระดับความหมายช่องทางต้องอนุมัติ
OBSERVEอ่าน/ค้นคว้า ไม่เปลี่ยนสถานะRead-only laneไม่
DRAFTร่างเนื้อหา/แผน/patch ไม่เขียนลงระบบจริงRead-only lane + artifact ชั่วคราวไม่
PREPAREเตรียมคำสั่งเสี่ยงสูง (staging, dry-run)Approval Gate → Side-effect laneใช่
EXECUTEเปลี่ยนระบบจริงภายนอกApproval Gate → Side-effect laneใช่ (บังคับ)

Approval 2 ชั้น

ชั้นที่ 1 อยู่ที่แผน (ก่อนมอบสิทธิ์เครื่องมือ) ชั้นที่ 2 อยู่ที่เครื่องมือ (needs_approval=True ทำให้ SDK หยุดรอ) รายละเอียดที่ Approval 2 ชั้น

Sandbox

SDK มี ShellTool, ApplyPatchTool ยืนยันแล้ว และ SandboxAgent ที่ต้อง import จาก agents.sandbox (ไม่ได้อยู่ที่ agents ระดับบนสุด) ยืนยันแล้ว ผลลัพธ์ที่เป็นไฟล์ควรผ่าน artifact boundary ที่กำหนด

ตัวอย่างการเดินทางของคำขอทีละขั้น และโค้ด dispatcher ดู Action Ladder
