ระนาบ 8 · Trust / Security

การป้องกันที่ทำงานคู่กับทุกระนาบ

หลักการความหมายในโค้ดตัวอย่าง
Zero Trustไม่เชื่อ input ใด ๆ รวมถึง output ของเครื่องมือPydantic validation
Least Privilegeให้สิทธิ์ขั้นต่ำToolAccessBroker
Secret Isolationแยกความลับออกจากโค้ดและพรอมต์อ่าน OPENAI_API_KEY จาก environment
Network Allowlistจำกัดปลายทางที่เชื่อมต่อได้ตั้งที่ sandbox / infrastructure
Fail-Closedผิดพลาดแล้วหยุดทันทีระดับที่ไม่รู้จักได้เครื่องมือว่าง; ไม่มีการอนุมัติ → PermissionError
