ข้อตกลงสถาปัตยกรรม

Architecture Contract เปลี่ยนระบบจาก “กระบวนการเดาสุ่ม” (stochastic) ไปเป็น “การกำกับที่คาดการณ์ได้” (deterministic governance) มี 4 ข้อที่บังคับใช้ทุกระนาบ

  1. ห้ามถือครองเครื่องมือถาวร
    agent ได้สิทธิ์ใช้เครื่องมือเฉพาะขั้นตอนย่อยที่กำลังทำ มีขอบเขตและหมดอายุเมื่องานจบ ไม่มี Global God-Agent → ระนาบ 4
  2. Exclusive State Ownership
    หนึ่งการสนทนามีเจ้าของสถานะรายเดียว ห้ามประสานสถานะสองทาง → ระนาบ 2
  3. ทุก side-effect ต้องมีเส้นทางอนุมัติที่ระบุชื่อได้
    ไม่มีการกระทำใดข้ามขอบเขตนโยบายได้หากไม่มี approval path → ระนาบ 5
  4. ห้ามแก้ตัวเองใน production
    การเรียนรู้เกิดในสภาพแวดล้อมคู่ขนานออฟไลน์ ผ่าน trace และ eval เท่านั้น → ระนาบ 7

ข้อตกลงทั้ง 4 ข้อนี้ถูกขยายเป็นกฎปฏิบัติ 2 ชุดที่ใช้คู่ขนานกัน ดู กฎ R และกฎ C
