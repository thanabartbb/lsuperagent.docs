จัดสรร ค้นหา และปล่อยเช่าเครื่องมือเฉพาะกิจ แทนการยัดทุกเครื่องมือลงพรอมต์

กลไกใน SDK

กลไกใช้ทำอะไรสถานะ
ToolSearchTool()ให้โมเดลโหลดเครื่องมือที่ถูกเลื่อนไว้ (deferred), namespace หรือ hosted MCP ตามต้องการยืนยันแล้ว
@function_tool(defer_loading=True)ไม่ส่งสคีมาเครื่องมือจนกว่าจะถูกค้นเจอยืนยันแล้ว
tool_namespace(name=, description=, tools=[...])จัดกลุ่มเครื่องมือให้ค้นเป็นกลุ่มยืนยันแล้ว
ProgrammaticToolCallingTool()ให้โมเดลเขียน JavaScript ประสานหลายเครื่องมือ ได้ ไม่เกิน 1 ตัวต่อเอเจนต์ยืนยันแล้ว
HostedMCPTool / agents.mcp.MCPServerStdioMCP แบบโฮสต์ (เซิร์ฟเวอร์ OpenAI เรียก) / แบบโลคัล (แอปคุณเรียก)ยืนยันแล้ว

Tool search และ Programmatic Tool Calling ใช้ได้เฉพาะ OpenAI Responses models ที่รองรับ (ตามเอกสารทางการ) ส่วนตัวเลข “gpt-5.4 ขึ้นไป” มาจากแหล่งภายนอก (LiteLLM) ยังไม่ยืนยัน ให้เช็กหน้ารุ่นโมเดลก่อนใช้ ToolSearchTool() ที่ไม่มีอะไรให้ค้น (ไม่มี deferred tool/namespace) จะถูกปฏิเสธ

Lease Broker ตามระดับ Action Ladder

# ---------------------------------------------------------------- Plane 4: capability leasing
@function_tool
def read_system_status(service_name: str) -> str:
    """Read a service's status (OBSERVE). SIMULATED: returns fixed text."""
    return f"[SIMULATED] service '{service_name}' is healthy"


@function_tool(needs_approval=True)
def restart_production_service(service_name: str) -> str:
    """Restart a production service (EXECUTE). SIMULATED: nothing is restarted."""
    return f"[SIMULATED] restart of '{service_name}' accepted"


class CapabilityLeaseBroker:
    """Lease only the tools allowed at the plan's Action Ladder level (R1, R9)."""

    @staticmethod
    def get_tools_for_level(level: ActionLadderLevel) -> list[Any]:
        if level in (ActionLadderLevel.OBSERVE, ActionLadderLevel.DRAFT):
            return [read_system_status]
        if level in (ActionLadderLevel.PREPARE, ActionLadderLevel.EXECUTE):
            return [restart_production_service]
        return []  # unknown level: lease nothing (fail-closed, R7)

ระดับที่ไม่รู้จักได้รายการว่าง (fail-closed) และถ้าโมเดลพยายามเรียกเครื่องมือที่ไม่ได้เช่า SDK จะโยน ModelBehaviorError — ทดสอบแล้วใน ทดสอบแบบออฟไลน์
