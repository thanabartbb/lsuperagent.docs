เพิ่มหน้าเอกสาร

เพิ่มหน้าใหม่ได้ด้วย 2 ขั้น ไม่ต้องแก้ core

  1. สร้างไฟล์เนื้อหา ที่ docs-content/<slug>.html (slug ใช้ a-z, 0-9, - เท่านั้น) 
    <h1>การ deploy</h1>
<p class="lead">คำอธิบายสั้น ๆ ใต้หัวเรื่อง</p>

<h2>หัวข้อย่อย</h2>
<p>เนื้อหา…</p>
<pre data-title="terminal"><code>npx wrangler deploy</code></pre>
  2. เพิ่มเมนู ใน assets/docs-nav.js 
    { slug: 'deploy', title: 'การ deploy', icon: 'rocket' },

หน้าใหม่จะอยู่ที่ /docs/deploy และขึ้นในเมนู ค้นหา สารบัญ และปุ่มก่อนหน้า/ถัดไปให้อัตโนมัติ

องค์ประกอบที่ใช้ได้

<pre data-title="…"><code>บล็อกโค้ดพร้อมชื่อไฟล์และปุ่มคัดลอก; {{BASE}} ถูกแทนด้วย API base URL
