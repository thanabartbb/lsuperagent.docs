ขึ้น production

ขั้นตอนเชื่อมตัวอย่างเข้ากับระบบจริง ทำทีละขั้นได้

  1. เชื่อมเครื่องมือกับระบบจริง
    แทนที่ตัวฟังก์ชันใน lab_harness.py ด้วยการเรียก API ของคุณ คง needs_approval=True ไว้กับเครื่องมือที่เปลี่ยนระบบ 
    import httpx

@function_tool
def read_system_status(service_name: str) -> str:
    """Read a service's status (OBSERVE)."""
    r = httpx.get(f"https://status.example.internal/api/{service_name}", timeout=10)
    r.raise_for_status()
    return r.text
  2. รันกับ OpenAI
    export OPENAI_API_KEY=... แล้ว python lab_harness.py
  3. เก็บสถานะถาวร
    ใช้ SQLiteSession("app.db") ครอบด้วย OpenAIResponsesCompactionSession ตาม State
  4. ตรวจข้ออ้างกับหลักฐาน
    ให้ trace grader ตรวจว่าทุกข้ออ้างใน final_claim ชี้กลับไปยัง tool_end ใน ledger ได้
  5. เพิ่ม test จากเหตุการณ์จริง
    เขียน trace ที่ผิดพลาดเป็น test ด้วย ScriptedModel
  6. ต่อ CI
    รัน pytest ใน GitHub Actions ทุก PR
