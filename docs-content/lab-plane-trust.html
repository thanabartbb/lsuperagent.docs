หลักการความหมายตัวอย่างในโค้ด
Zero Trustinput ทุกชนิด รวมถึง output จากเครื่องมือ ไม่น่าไว้ใจPydantic schema validation ก่อนเข้าโมเดล

Secret Isolationแยกความลับออกจากโค้ดและพรอมต์อ่าน OPENAI_API_KEY จาก environment เท่านั้น
Network Allowlistจำกัดปลายทางที่ออกได้ตั้งที่ sandbox / infrastructure
Fail-Closedผิดพลาดเมื่อไหร่ หยุดทันทีระดับที่ไม่รู้จัก → ไม่มอบสิทธิ์เครื่องมือใดเลย; ไม่มีการอนุมัติ → PermissionError
