การตั้งค่า client

ตัวเลือกทั้งหมดของ new Lsupergen(options)

import { Lsupergen } from 'lsupergen-sdk';

const client = new Lsupergen({
  apiKey: process.env.LSUPERGEN_API_KEY,
  baseURL: '{{BASE}}',
  timeout: 60_000,
  maxRetries: 2,
  defaultHeaders: { 'X-App': 'my-agent' },
});

ตัวเลือก

ตัวเลือกชนิดค่าเริ่มต้น
apiKeystringLSUPERGEN_API_KEY (ไม่มี = throw ตอนสร้าง client)
baseURLstringLSUPERGEN_BASE_URL หรือ https://api.lsupergen.com
timeoutnumber (ms)60000
maxRetriesnumber2
defaultHeadersobject{}
fetchfunctionglobalThis.fetch

ต้องตั้ง baseURL เป็น … เสมอ ค่าเริ่มต้น api.lsupergen.com ไม่ใช่ API ของเว็บนี้

เมธอด

client.get(path, options?)
client.post(path, options?)
client.put(path, options?)
client.patch(path, options?)
client.delete(path, options?)
client.request(method, path, options?)

ตัวเลือกต่อคำขอ

bodyแปลงเป็น JSON และตั้ง Content-Type ให้
queryobject → query string (ข้าม null/undefined)
headersheader เพิ่มเฉพาะคำขอนี้
timeout, maxRetriesoverride ค่าของ client
signalAbortSignal สำหรับยกเลิก
