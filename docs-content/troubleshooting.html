การแก้ไขปัญหา

อาการที่พบบ่อยและวิธีแก้

ConnectionError ในเบราว์เซอร์หรือ Workers

สาเหตุคือบั๊กใน 0.1.0 (Illegal invocation) ส่ง fetch: (...args) => fetch(...args) ตอนสร้าง client หรืออัปเดตเป็น 0.1.1

401 invalid_api_key

  • key หมดอายุ (30 วัน) — สร้างใหม่ที่ Playground
  • คัดลอก key ไม่ครบ — ต้องขึ้นต้นด้วย lsg_
  • ผู้ดูแลเปลี่ยน AUTH_SESSION_SECRET — key เก่าใช้ไม่ได้ทั้งหมด

เรียกไปผิดที่ / DNS error

ลืมตั้ง baseURL ทำให้ SDK เรียก api.lsupergen.com ให้ตั้งเป็น …

503 service_unavailable

ระบบยังไม่ได้ตั้ง OPENAI_API_KEY ตรวจด้วย GET /health ว่า ai_ready เป็น true

429 rate_limited

เกิน 10 คำขอ / 10 นาที SDK จะรอตาม Retry-After ให้เอง 2 ครั้ง ถ้ายังเกินให้ลดความถี่

Missing API key ตอนสร้าง client

ไม่ได้ส่ง apiKey และไม่มี LSUPERGEN_API_KEY ใน environment ใน Workers ต้องส่ง apiKey: env.LSUPERGEN_API_KEY เอง
