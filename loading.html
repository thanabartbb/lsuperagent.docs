Get Started

From sign-in to your first API request.

  1. Sign inOpen the AI workspace with your account.
  2. Create an API keyGenerate a key at /keys and keep a copy. Keys expire after 30 days.
  3. Install the SDKCall /v1/chat or /v1/image from your code.
// npm install lsupergen-sdk
// Set LSUPERGEN_API_KEY with a key created at /keys
import { Lsupergen } from 'lsupergen-sdk';

const client = new Lsupergen({
  baseURL: 'https://agents-sdk.space/v1',
});
const me = await client.get('/me');
const reply = await client.post('/chat', { body: { message: 'Hello' } });
