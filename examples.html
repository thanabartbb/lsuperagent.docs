SDK · PLUG · TOOLS

SDK Plug Tools

ปลั๊กอิน SDK และเครื่องมือสำเร็จรูปสำหรับเชื่อมต่อ lsuperagen เข้ากับระบบของคุณ — ติดตั้งครั้งเดียว ใช้ได้ทุกที่

$ pnpm add @lsuperagen/sdk

CORE SDK

@lsuperagen/sdk

แพ็กเกจหลักสำหรับเชื่อมต่อทุก service ของ lsuperagen จาก Node.js หรือ Edge Runtime

import { LsuperagenClient } from "@lsuperagen/sdk" const client = new LsuperagenClient({ projectId })
Stable

@lsuperagen/sdk-react

React hooks และ Provider components พร้อมใช้ รองรับ Next.js App Router และ RSC

import { useLsuperagen } from "@lsuperagen/sdk-react" const { writer, researcher } = useLsuperagen()
Stable

@lsuperagen/sdk-edge

Lightweight build สำหรับ Cloudflare Workers, Vercel Edge Functions และ Deno Deploy

import { createEdgeClient } from "@lsuperagen/sdk-edge" // ใช้กับ wrangler.toml + workers_dev = true
Beta

AUTH PLUGINS

auth-supabase

เชื่อม Supabase Auth เป็น primary provider รองรับ email, magic link และ OAuth

import { SupabaseAuthPlugin } from "@lsuperagen/sdk" client.use(SupabaseAuthPlugin({ url, anonKey }))
Stable

auth-firebase

Firebase Auth เป็น fallback provider เปิดใช้เมื่อ Supabase trigger: network / provider_down / config_missing

import { FirebaseAuthPlugin } from "@lsuperagen/sdk" client.use(FirebaseAuthPlugin({ apiKey, authDomain }))
Beta

auth-session

จัดการ session ข้ามแท็บและ refresh token อัตโนมัติ รองรับ SSR

import { SessionPlugin } from "@lsuperagen/sdk" client.use(SessionPlugin({ persist: true }))
Stable

TOOL PLUGINS

plugin-writer

AI Writer plugin — สร้างและแก้ไขคอนเทนต์ผ่าน SDK ปรับ tone, length และ format ได้

const result = await client.writer.generate({ prompt: "...", tone: "professional" })
Beta

plugin-image

Image Generator plugin — สร้างภาพจาก prompt รองรับหลาย model และ output format

const img = await client.image.generate({ prompt: "...", size: "1024x1024" })
Beta

plugin-research

Deep Research plugin — ค้นคว้า สรุป และสร้าง structured report พร้อม citation

const report = await client.research.run({ query: "...", depth: "deep" })
Beta

plugin-code

Code Assistant plugin — เขียน แก้ไข review และอธิบายโค้ด รองรับ 40+ ภาษา

const fix = await client.code.review({ code: sourceCode, lang: "typescript" })
Beta
