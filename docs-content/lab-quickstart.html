ติดตั้งและรัน

รันสถาปัตยกรรมขั้นต่ำ (minimal vertical slice) ได้ทันทีแบบออฟไลน์ ไม่ต้องมี API key

หลักการ: อย่าเริ่มจากสภา Creative Friction เต็มรูปแบบ ทำเส้นทางแนวดิ่งขั้นต่ำให้ครบวงจรก่อน แล้วเก็บ trace จริง
Intent Envelope → State Ownership Gate → Action Classifier → Approval Gate → Capability Lease Broker → Runner → Evidence Spine → Trace Grader

1. ดาวน์โหลดไฟล์

lab_harness.py · lab_patterns.py · test_lab.py · test_patterns.py · requirements.txt

2. ติดตั้ง

python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
openai-agents==0.22.3
pydantic>=2
pytest

3. รันแบบออฟไลน์

OPENAI_AGENTS_DISABLE_TRACING=1 python lab_harness.py --offline

ผลลัพธ์ที่ได้จริง:

check payment-gateway status -> {'status': 'DONE', 'level': 'OBSERVE', 'output': 'read_system_status finished for payment-gateway', 'trace_score': 1.0, 'trace_status': 'PASS', 'entries': 4}
restart payment-gateway to fix latency -> {'status': 'DONE', 'level': 'EXECUTE', 'output': 'restart_production_service finished for payment-gateway', 'trace_score': 1.0, 'trace_status': 'PASS', 'entries': 5}

4. รันกับ OpenAI จริง

export OPENAI_API_KEY=sk-...
python lab_harness.py

โหมดนี้จะถามอนุมัติในเทอร์มินัลสองครั้งสำหรับงาน restart (ชั้นแผน + ชั้นเครื่องมือ) ถ้าไม่ระบุ model SDK ใช้โมเดลเริ่มต้นของเวอร์ชันที่ติดตั้ง

5. รันชุดทดสอบ

OPENAI_AGENTS_DISABLE_TRACING=1 python -m pytest -q test_lab.py test_patterns.py

ผลที่ตรวจแล้ว: 10 passed
