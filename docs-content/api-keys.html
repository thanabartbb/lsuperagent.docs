API key

API key ใช้ยืนยันตัวตนทุกคำขอ ยกเว้น /health

สร้าง key

  1. เข้าสู่ระบบที่ agents-sdk.space
  2. เปิดหน้า API keys แล้วกด “สร้าง key ใหม่” จากนั้นกด “คัดลอก key” (key ไม่แสดงเต็มบนหน้าจอ)
  3. คัดลอก key ทันที — ระบบแสดงครั้งเดียวและไม่เก็บไว้ให้ดูซ้ำ

คุณสมบัติของ key

รูปแบบlsg_ + token ที่เซ็นด้วยกุญแจของเซิร์ฟเวอร์
อายุ30 วันนับจากวันสร้าง
ผูกกับบัญชีที่สร้าง (ดูได้จาก GET /me)
จำนวนสร้างได้หลายตัว แต่ละตัวมี key.id ของตัวเอง

การส่ง key

SDK ส่ง header ให้อัตโนมัติ ถ้าเรียกเองให้ใส่:

Authorization: Bearer lsg_your_key_here

ความปลอดภัย

อย่า commit key ลง Git และอย่าฝังในโค้ดฝั่งเบราว์เซอร์ที่เผยแพร่ เก็บเป็น environment variable หรือ wrangler secret put

key ไม่มีการเก็บในฐานข้อมูล จึงยกเลิกทีละตัวไม่ได้ ถ้า key หลุดให้หยุดใช้และรอหมดอายุ หรือให้ผู้ดูแลเปลี่ยน AUTH_SESSION_SECRET ซึ่งจะยกเลิก key และ session ทั้งหมดพร้อมกัน
