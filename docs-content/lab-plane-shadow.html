ระนาบ 7 · Shadow Reflection

ระบบเรียนรู้จากความผิดพลาดแบบออฟไลน์ แล้วปล่อยเวอร์ชันใหม่หลังผ่านการประเมิน

  1. Failure Clusterer จัดกลุ่ม trace ที่คะแนนต่ำ
  2. Shadow Reflection Agent วิเคราะห์สาเหตุ เสนอการแก้พรอมต์ ทักษะ หรือนโยบาย
  3. Offline Eval Run ยืนยันว่าไม่เกิด regression
  4. Promotion Gate ผ่านแล้วเป็นเวอร์ชัน vN+1
  5. เก็บ rollback point ทุกครั้ง

ปัญหาที่พบแต่ละครั้งเขียนเป็น test ด้วย ScriptedModel ได้ ดู ทดสอบแบบออฟไลน์
