Explicit Planes

ทุกส่วนต้องเป็น module ที่มองเห็น ตรวจได้ และย้าย runtime ได้ภายหลัง

RUNTIME

Runtime Plane

เลือก Agents SDK, Responses API, MCP bridge หรือ external operator ตามงาน

TOOLS

Tool Plane

catalog ของ tools, Zapier, Remote SDK, MCP, GitHub actions และ endpoint contract

GUARDRAILS

Guardrail Plane

ตรวจ input, output, tool args, policy, redaction และ risk ก่อน side effect

APPROVALS

Approval Plane

pause action สำคัญให้ owner approve / reject พร้อม state ที่ resume ได้

TRACES

Trace Plane

index การรัน: model call, tool call, handoff, guardrail และ interruption

EVALS

Eval Plane

grader, datasets, regression checks และ score ของ workflow

EVIDENCE

Evidence Plane

หลักฐาน deploy, logs, screenshots, source bundle และ output archive

COMPACTION

Compaction Plane

สรุป state งานยาว ลด context cost และทำ handoff ข้าม agent

Execution Flow

จาก intent ไป action จริงโดยไม่ปล่อยให้ agent ยิง side effect แบบมืด

01
Intentรับคำสั่งจาก owner / app / external agent
02
Proposeagent เสนอ tool/action และ arguments
03
Guardrailตรวจ secret, scope, route, policy, risk
04
Approvalงานเสี่ยงสร้าง approval item ก่อน run
05
ExecuteZapier / MCP / GitHub / Worker run จริง
06
Evidenceเก็บ trace, result, eval, artifact pointer
