Architecture Planes

ใช้เป็นสารบัญระบบก่อนต่อ activity-hub.online หรือ markdown link network ภายหลัง

RUNTIME

Runtime Plane

นิยามตำแหน่งของ Agents SDK, Responses API, MCP bridge, หรือ external operator

TOOLS

Tool Plane

catalog ของ tools, MCP, Zapier, Remote SDK, GitHub และ endpoint contract

GUARDRAILS

Guardrail Plane

นโยบายตรวจ input, output, tool args, redaction และ risk ก่อน side effect

APPROVALS

Approval Plane

ข้อกำหนดการ pause / approve / reject สำหรับ action ที่เสี่ยง

TRACES

Trace Plane

กรอบการบันทึก model call, tool call, handoff, guardrail, interruption

EVALS

Eval Plane

grader, dataset, eval run และ regression criteria สำหรับ agent workflow

EVIDENCE

Evidence Plane

หลักฐานการทำงานจริง: logs, screenshot, source bundle, deploy result

COMPACTION

Compaction Plane

สรุป state งานยาวและ handoff ข้าม agent เพื่อไม่ให้ context กระจาย
